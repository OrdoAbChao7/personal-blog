## 项目动机

县域产业的衰败与升级，是一个被主流研究机构系统性忽视的命题。传统券商报告只覆盖上市公司，地方智库又缺数据工程能力。

我想做一个**能自动采集、清洗、交叉验证产业数据并产出结构化研究简报**的 Agent 系统，把县域产业研究变成可批量复制的工作流。

## 系统架构

```
[规划 Agent] → [采集 Agent] → [清洗 Agent] → [分析 Agent] → [写作 Agent]
     │              │              │              │              │
     └──────────────┴──────────────┴──────────────┴──────────────┘
                              共享记忆层
```

- **规划 Agent**：根据研究主题拆解子问题，输出研究大纲
- **采集 Agent**：多源抓取（统计局、企查查、新闻、招聘、招投标）
- **清洗 Agent**：实体对齐、单位归一、去重
- **分析 Agent**：产业链上下游映射、竞争格局、估值水位
- **写作 Agent**：输出符合券商研报规范的结构化简报

## 设计取舍

没有用单 Agent + 工具调用的方案，而是选了多 Agent 图（LangGraph）。原因：县域研究的链路太长，单 Agent 上下文会爆；多 Agent 之间可以并行采集、串行分析，且每一步可单独调试。
