## 通用 Agent 的幻觉

过去一年，"通用 AI Agent"是被过度承诺的概念。演示里它能订机票、写代码、做投研，实际落地时却在最简单的多步任务上崩溃。

根本原因：**通用 Agent 试图用一套提示词覆盖所有场景的决策空间，而 LLM 的可靠性会随步骤数指数衰减**。每一步 90% 的准确率，十步链路下来只剩 35%。

## 垂直 Agent 的优势

垂直 Agent 的核心不是"换一个领域的提示词"，而是**把领域知识固化成可复用的工具与校验规则**，让 Agent 只负责调度，不负责"懂"。

以我做 CountyResearchAI 的经验为例：

| 维度 | 通用 Agent | 垂直 Agent |
|---|---|---|
| 数据源 | 临时搜索 | 预置可信数据源 |
| 校验 | LLM 自检 | 规则 + 交叉比对 |
| 失败恢复 | 重试 | 回滚到上一节点 |
| 评估 | 主观 | 行业评分卡 |

## 真正的机会

通用 Agent 是巨头的游戏（OpenAI、Anthropic、Google）。创业者和工程师的机会在**垂直场景的 Know-How 沉淀**——你比模型更懂某个领域的脏数据、潜规则、决策树。

谁把这些固化成系统，谁就拥有壁垒。模型会迭代，但领域工程不会贬值。

## 结论

别再追"通用智能"。找一个你真正懂的垂直领域，把它的研究流程拆成 Agent 图，让模型做苦力，让规则做守门员。这才是 2026 年 Agent 落地的务实路径。
